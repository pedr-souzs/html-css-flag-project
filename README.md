# HTML CSS Flag Gallery

Projeto de prática em HTML e CSS desenvolvido para explorar conceitos fundamentais de layout, Box Model e propriedades de exibição por meio da criação de bandeiras estilizadas.

## Sobre o projeto

O projeto consiste na criação de cinco bandeiras utilizando exclusivamente HTML e CSS, sem o uso de imagens externas.

As bandeiras são construídas com elementos HTML e propriedades CSS, permitindo praticar diferentes formas de organização e dimensionamento dos elementos.

## Bandeiras

O projeto inclui cinco bandeiras entre as seguintes opções:

* França
* Bélgica
* Itália
* Alemanha
* Rússia
* Holanda
* Polônia

## Tecnologias utilizadas

* HTML5
* CSS3

## Conceitos praticados

* Box Model
* `display: inline`
* `display: block`
* `display: inline-block`
* Width e height
* Margin e padding
* Border
* Estruturação de elementos
* Posicionamento e organização de elementos com CSS

## Restrições do projeto

As bandeiras foram desenvolvidas exclusivamente com HTML e CSS.

Não foram utilizadas imagens para representar as bandeiras.

## Objetivo

Praticar os fundamentos de HTML e CSS, especialmente o funcionamento do Box Model e os diferentes comportamentos proporcionados pelas propriedades `inline`, `block` e `inline-block`.
